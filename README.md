# Dreamio Frontend Design (React Native + Tailwind)

This UI prototype implements the requested user flows:

- Authentication: sign in / sign up (name, email, password, birthday)
- Social auth CTAs (Google, Facebook)
- Dream analysis with a text field and result card
- Emotion-aware icon rendering (example: happy dream shows 🐶)
- Dream history list with multi-select support
- Bulk analysis summary with past/present/future insight
- Profile management (editable name + password update)
- Dream deletion from history

## Run

```bash
npm install
npm run start
```

Uses **NativeWind** for Tailwind-style utilities in React Native.
